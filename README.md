# GIT REPO Referat univariate Zeitreihenprognose

In diesem Repo befindet sich der Code der zentraler Bestandteil des Referates ist.

Verwendungsanleitung:
1. GitRepo lokal klonen mit: 
git clone https://github.com/TobiVoth/Forcast_Transformer.git
2. Virtuelle Python umgebung einrichten: python -m venv venv
3. Packete installieren: pip install -r requirements.txt
4. main.py enthält erste Codebeispiele (Daten abrufen und plotten). Das kann testweise ausgeführt werden mit "py main.py"
